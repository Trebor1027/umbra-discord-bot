# Proyecto UMBRA
### Bayonetta Discord Bot

**Python · Discord.py · SQLite · OpenAI · FFmpeg**

Un bot de Discord inspirado en el universo de Bayonetta, desarrollado como proyecto personal para explorar la programación, la automatización y la inteligencia artificial.

---

## Sobre el proyecto

Proyecto UMBRA nació como una forma de poner en práctica mis conocimientos de Python y aprender a desarrollar aplicaciones más completas.

Lo que comenzó con unos pocos comandos básicos fue evolucionando hasta convertirse en un bot con sistemas de economía, niveles, memoria e integración de inteligencia artificial.

Uno de los principales objetivos del proyecto es crear un asistente que no se limite a responder comandos, sino que tenga una personalidad reconocible y pueda recordar información de sus usuarios.

## Funcionalidades

| Sistema | Descripción |
|---|---|
| Comandos básicos | Interacción con los usuarios y respuestas automáticas. |
| Moderación | Herramientas para administrar mensajes y usuarios. |
| Economía | Monedas virtuales, recompensas, trabajos, tienda y transferencias. |
| Niveles | Sistema de progresión basado en la actividad. |
| Memoria | Almacenamiento y recuperación de información mediante SQLite. |
| Inteligencia artificial | Respuestas generadas mediante OpenAI, con personalidad personalizada. |
| Audio | Reproducción de audio mediante FFmpeg. |

## Tecnologías utilizadas

- **Python:** lenguaje principal del proyecto.
- **discord.py:** comunicación e interacción con Discord.
- **SQLite:** almacenamiento de información.
- **OpenAI API:** integración de inteligencia artificial.
- **FFmpeg:** procesamiento y reproducción de audio.
- **Git y GitHub:** control de versiones y seguimiento del desarrollo.

## Proceso de desarrollo

El proyecto se ha desarrollado progresivamente, incorporando nuevas funcionalidades a medida que he ido adquiriendo conocimientos.

**01 — Primeros pasos**

Configuración del entorno de desarrollo, conexión con Discord y creación de los primeros comandos.

**02 — Administración y economía**

Implementación de herramientas de moderación y un sistema de economía virtual con saldo, recompensas, tienda y transferencias.

**03 — Sistema de niveles**

Desarrollo de un sistema para registrar la actividad y progresión de los usuarios.

**04 — Persistencia de datos**

Integración de SQLite para almacenar información y permitir su recuperación entre ejecuciones.

**05 — Inteligencia artificial**

Conexión con OpenAI y desarrollo de una personalidad inspirada en Bayonetta, combinando respuestas inteligentes con información almacenada.

**06 — Funcionalidades de audio**

Integración de FFmpeg para incorporar reproducción de audio al bot.

## Estado actual

**En desarrollo activo.**

El proyecto continúa evolucionando. Entre las mejoras previstas se encuentran una memoria más avanzada, una personalidad más natural y una mejor organización interna del código.

## Objetivo personal

Más allá de crear un bot funcional, este proyecto representa una oportunidad para aprender a diseñar, desarrollar y mantener software.

Cada funcionalidad ha supuesto nuevos desafíos y conocimientos relacionados con Python, bases de datos, APIs y automatización.
